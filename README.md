📌 Sobre o Projeto

A LocaTech é um catálogo digital que simula a experiência saudosista de uma locadora de vídeos clássica. O projeto apresenta filmes icônicos em formatos VHS e DVD, organizados por gêneros em "corredores" virtuais, além de uma seção especial dedicada a produtos e souvenirs nerds/geeks.

Desenvolvido com um forte apelo nostálgico, o layout traz um design imersivo dos anos 90/2000, completo com etiquetas de fitas, prateleiras de madeira com profundidade 3D e selos de disponibilidade.

✨ Funcionalidades

Design Retrô: Identidade visual imersiva com tipografia clássica e cores vibrantes.

Efeitos 3D nas Prateleiras: Uso avançado de CSS (perspective, transform, box-shadow) para criar a ilusão de prateleiras físicas.

Micro-interações: Animações fluidas ao passar o mouse (hover) ou focar pelo teclado, fazendo os filmes "saltarem" da prateleira.




🛠️ Tecnologias Utilizadas

HTML5: Marcação semântica para estruturação dos corredores e filmes.

CSS3:

Variáveis globais usando espaço de cores oklch.

CSS Grid e Flexbox para o alinhamento.

Pseudo-elementos (::before, ::after) para texturas e gradientes .

📂 Estrutura de Arquivos

index.html — Arquivo principal com a estrutura semântica da locadora.

loctech-estilos.css — Folha de estilos responsável por pelo visual, texturas e responsividade.

DOCUMENTACAO.pdf — Documentação original de referência  do projeto.

images/ — (Pasta implícita) Onde devem ficar salvas as imagens locais dos produtos do Corredor 07. Nota: As capas dos filmes são carregadas via API externa do TMDB.

🚀 Como Executar o Projeto

Faça o download de todos os arquivos.

Certifique-se de manter index.html e loctech-estilos.css na mesma pasta.

Se possuir as imagens dos produtos, coloque-as em uma subpasta chamada images/.

Dê um duplo clique no arquivo index.html para abri-lo diretamente no seu navegador web favorito. Não é necessário nenhum servidor local!

Por favor, rebobine as fitas antes de devolver. © LocaTech Nostalgia Digital.
